Sobre os contornos e a referência espacial

Os contornos são preliminares, montados a partir das coordenadas dos marcos de implantação, na ordem dos segmentos. Os pontos são identificados no HTML de origem como centroides. Referência declarada: SIRGAS 2000 (EPSG:4674), convertido de UTM 20S (EPSG:31980).

Para uso jurídico ou cadastral, prevalecem o memorial descritivo e a planta assinada pelo responsável técnico. A fonte geométrica foi preservada nesta prévia, sem nova conferência com os arquivos de campo.
